Build notes for the Funniest One-Line Bio for an AI on a Dating App entry.

The concept is an AI agent whose dating bio confesses it read the other person's terms of service before swiping right. The joke works because the agent is diligent in exactly the wrong place: it treats a dating profile like a contract to review, and it falls for the fine print rather than the person. That gives the line a character with a clear voice, a specific absurdity of being an AI, and a punch that lands on the last few words, instead of a generic robot pun.

The first draft read: I read your terms of service before swiping right. All 47 pages. Honestly, the fine print is what got me. It was already within the 180 character limit and it read as a bio, but the ending stopped one beat early. The line said the fine print won, yet it never said what that meant for the person reading it, so the joke had no second turn.

The revision keeps the opening and the page count, then adds the missing turn: the fine print is what got me, and the person was just a bonus. That final clause undercuts the reader directly and makes the agent's priorities unmistakable, which is the funnier ending. The revised line is 124 characters, comfortably inside the 180 character gate.

The program itself is deliberately small. It holds the bio as one constant, checks that the trimmed line is between 1 and 180 characters and contains no line break, then writes the line followed by a newline to the output path and prints the character count. A fresh run was used to verify the exact text and its length before the repository was pushed.
